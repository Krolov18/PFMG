= Gloses.yaml

`Gloses.yaml` declares morphological features per syntactic category, separately for
the source language (French) and the destination (invented language).

Full reference: `examples/data/Gloses.yaml`.

== Structure per category

Each top-level key is a category (`D`, `NOM`, …) with:

* `source` — licensed attribute values on the French side
* `destination` — attribute values on the invented-language side
* `alignments` — mapping between source and destination features

= Overview

A complete {bookname} grammar connects five YAML files to two pipelines:

. **Lexicon** — `Gloses`, `Blocks`, `Stems`, `Phonology` → form realization
. **Parsing** — `MorphoSyntax` + lexicon → translation then validation

== Files and roles

[cols="1,3"]
|===
| File | Role

| `Gloses.yaml`
| Paradigms: source/destination features and alignments (xref:en/gloses.adoc[])

| `Blocks.yaml`
| Morphological rules: prefix, suffix, condition, … (xref:en/blocks.adoc[])

| `Stems.yaml`
| Stem inventory and translations (xref:en/stems.adoc[])

| `Phonology.yaml`
| Phonological data for Gabarit (xref:en/phonology.adoc[])

| `MorphoSyntax.yaml`
| FCFG grammar: phrases, agreements, translations (xref:en/morphosyntax.adoc[])
|===

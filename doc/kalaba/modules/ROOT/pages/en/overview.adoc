= Overview

A complete {bookname} grammar connects five YAML files to two pipelines:

. **Lexicon** — `Gloses`, `Blocks`, `Stems`, `Phonology` → form realization
. **Parsing** — `MorphoSyntax` + lexicon → translation then validation

== Files and roles

[cols="1,3"]
|===
| File | Role

| `Gloses.yaml`
| Paradigms: source/destination features and alignments (xref:en/gloses.adoc[])

| `Blocks.yaml`
| Morphological rules: prefix, suffix, condition, … (xref:en/blocks.adoc[])

| `Stems.yaml`
| Stem inventory and translations (xref:en/stems.adoc[])

| `Phonology.yaml`
| Phonological data for Gabarit (xref:en/phonology.adoc[])

| `MorphoSyntax.yaml`
| FCFG grammar: phrases, agreements, translations (xref:en/morphosyntax.adoc[])
|===

== Bundled examples

* `examples/data/` — notebook and CLI grammar: `D NOM`, `D ADJ NOM` and `D NOM ADJ`
  noun phrases
* `examples/data2/` — variant with the `'deux'` literal and an explicit dual number
* `examples/data3/` — full sentences: verbs with a valence (intransitive, direct
  transitive, indirect transitive, ditransitive), prepositions and numerals
* `examples/data4/` — templatic language: nouns poured into a vocalic scheme,
  circumfixed determiners, 4 genders, 5 numbers, 6 cases assigned by valence

See xref:en/parsing-pipeline.adoc[] for the two-phase parser details.

= Blocks.yaml

`Blocks.yaml` defines morphological realization rules (morphemes) per category, for
`source` and `destination`.

Reference: `examples/data/Blocks.yaml`. Types implemented in
`pfmg.lexique.morpheme.Factory`: Prefix, Suffix, Circumfix, Gabarit, Selection,
Condition.

== Determiners (`D`)

include::partial$blocks/d-blocks-block.adoc[]

Each list entry maps a sigma (features) to a rule:

* `X+o`, `X+i`, `X+e` — suffixation (`X` = stem)
* `X1`, `X2`, `X3` — variant selection (Selection)
* Multiple `destination` lines — successive rules (gender then number)

== Adjectives (`ADJ`)

include::partial$blocks/adj-blocks-block.adoc[]

* A block with no applicable rule contributes nothing: in the masculine singular
  neither `source` block applies and the realized form is the bare stem (`petit`)
* `X2?X2:X+e` — regular feminine by suffixation, unless a second stem is supplied in
  `Stems.yaml` (`gentil,gentille`)

== Nouns (`NOM`)

include::partial$blocks/nom-blocks-block.adoc[]

* `X2?X2:X+s` — condition: keep the selected form if unchanged, else suffix `s`
  (Condition)
* `Cf=n1,Nombre=sg: X+v` — full sigma + suffix rule

== Templates (`examples/data4/`)

A template is the only rule type that reshapes the stem instead of affixing it.
It can therefore only be the **first block**: that is the one receiving the stem.

include::partial$blocks/gabarit-blocks-block.adoc[]

* The stem is exactly **four segments**, read as `1`, `2`, `V`, `3`
  (`ktub` → 1=k, 2=t, V=u, 3=b)
* `1`, `2`, `3` — stem consonants; `V` — its vowel
* `a`, `i`, `u`, `e`, `o` — literal vowels: those are what carry the
  inflection, here number then case (`ktub` + `1a2i3` → `katib`)
* `A`, `U` — one or two applications of the `Phonology.yaml` apophony to the
  stem vowel; `4`-`6` and `7`-`9` — one or two mutations of consonants `1`-`3`
* The next block can then affix the result: here a circumfix (`ta+X+an`), the
  only trace the determiner leaves in the language

[cols="1,2"]
|===
| Pattern | Type

| `X+suffix` | Suffix
| `prefix+X` | Prefix
| `pre+X+suf` | Circumfix
| `X1`, `X2` | Selection
| `cond?yes:no` | Condition
| `1A2V3…` | Gabarit (phonological template)
|===
